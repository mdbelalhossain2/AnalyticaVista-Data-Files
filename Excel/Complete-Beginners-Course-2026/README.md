# Microsoft Excel for Beginners — Complete Excel Course 2026

These downloadable files accompany the AnalyticaVista YouTube video:

**Microsoft Excel for Beginners | Complete Excel Course 2026**

## Course Files

### 1. Starter Workbook

[Download the Starter Workbook](./01_Excel_Course_Starter.xlsx.xlsx?raw=1)

Start the course with this workbook. It contains the original column headings and the first five fictional participant records. During the course, you will enter Participant P006 and practice entering, editing, organizing, and formatting data.

### 2. Full 200-Participant Dataset

[Download the 200-Participant Dataset](./02_Workforce_Training_Data_200_Participants.xlsx.xlsx?raw=1)

Use this workbook when the course transitions from the small practice dataset to the complete dataset. It contains 200 fictional participant records for practicing formulas, functions, Tables, sorting, filtering, data cleaning, and analysis.

### 3. Completed Course Workbook

[Download the Completed Workbook](./03_Excel_Course_Completed_Workbook.xlsx.xlsx?raw=1)

Use this workbook after completing the course to compare your work with the finished project. It includes the completed formulas, functions, data cleaning, XLOOKUP results, PivotTables, charts, final report, and PDF-ready output.

## Recommended Learning Sequence

1. Begin with the **Starter Workbook**.
2. Follow the video until instructed to use the full dataset.
3. Continue with the **200-Participant Dataset**.
4. After completing the course, compare your work with the **Completed Course Workbook**.

## Dataset Notice

All information in these workbooks is fictional and was created solely for educational purposes. The files do not contain information about real participants, employees, programs, staff members, or organizations.
